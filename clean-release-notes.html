0.1.22

  • Produktnavnene er nu Visual Designer for editoren og Visual Designer Manager for hele WordPress-pakken; interne kompatibilitetsidentifiers er bevidst bevaret.
  • Hierarkiet håndhæves: Sektion må kun ligge på sideniveau, Kasse må ligge i Sektion/Kasse, og Tekst/Billede skal ligge i en Sektion eller Kasse.
  • Ulovlige drag/drop-placeringer afvises i editoren med tydelig visuel feedback og forklaring.
  • Ældre 0.1.21-layouts normaliseres kompatibilitetssikkert: root-elementer pakkes i neutrale Sektioner, og historiske nested Sektioner konverteres til Kasser uden at slette børn eller indhold.
  • Ny Menu / Navigation-administration kan oprette menuer, tilføje sider/custom links, redigere rækkefølge og parent-hierarki, tildele theme locations samt gemme og gendanne snapshots.
  • Ny Export-administration kan eksportere plugin, aktivt tema, sider, navigation, billeder, dokumenter, video eller alle medier som ZIP med manifest og SHA-256-integritet.
  • Ny Tema / Shell-side viser aktivt tema, parent theme, theme supports og menu-locations uden endnu at ændre den offentlige theme-runtime.
  • Desktop/Laptop/Mobil, Preview, Save/versioner, manuel billedgeometri og responsive frontend-rendering fra 0.1.21 er bevaret og indgår i regressions-QA.
