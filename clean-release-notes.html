0.1.58 – Side Designer Gem → frontend synkronisering

  • BUG-20: Side Designer → Gem toucher nu WordPress-siden efter den canonical Designer-model er gemt, så save_post/post_updated-baserede caches ser den nye version.
  • Der køres desuden clean_post_cache() efter hver Designer-gemning og restore.
  • En Gem uden nye layoutændringer invaliderer også frontend-cache, så en stale offentlig side kan repareres uden en falsk ny version.
  • Gem & vis åbner den gemte side med versions-cache-buster.
  • Menuadministrationen er ikke ændret i denne release.

0.1.57 – Menu-save og runtime-identitet

  • BUG-19: Menu → Gem serialiserer nu WordPress menu-item CSS-klasser som streng og kan derfor ikke længere sende et array ind i WordPress explode().
  • Samme klasseserialisering bruges ved menuoverskrifter og navigation-snapshot restore.
  • VD-RUNTIME-IDENTITY-001: aktive PHP-klasser bruger nu VisualDesignerManager\… i stedet for Hangar18\Clean\…, og Text Domain er visual-designer-manager.
  • Eksisterende h18_clean/h18-clean option-, meta-, action- og side-slugs bevares med vilje for data- og URL-kompatibilitet.

0.1.56 – Forenklet visuel Menu

  • VD-MENU-UX-003: Menuadministrationen viser nu menupunkterne som en visuel, trækbar liste i stedet for en teknisk WordPress-tabel.
  • + Tilføj menupunkt giver et enkelt valg mellem publicerede sider, eksternt link og overskrift/gruppe; kladder og dubletter filtreres fra standardflowet.
  • Undermenuer kan laves med ↳ / ← og drag-and-drop; menutekst redigeres direkte, og Fjern fra menu sletter aldrig destinationssiden.
  • Desktop/Mobil struktur-preview opdateres live, mens theme-locations, flere menuer og versionshistorik er flyttet under Avancerede indstillinger.

0.1.55 – Sidehandlinger

  • VD-PAGES-ACTIONS-001: Manager → Sider har nu separate knapper til Publicér, Gør til kladde, Sæt som Hjem og Slet.
  • Sæt som Hjem ændrer kun WordPress-hjemmesiden og publicerer ikke længere siden automatisk.
  • Slet flytter siden til WordPress-papirkurven efter bekræftelse; siden kan derfor gendannes.
  • Den aktive hjemmeside er beskyttet mod Gør til kladde og Slet, indtil en anden hjemmeside er valgt.

0.1.54 – Menu UX og Kladde/Publicér

  • VD-MENU-UX-002: Manager → Menu får drag-and-drop/pilebaseret rækkefølge, tydelig undermenu-parent og beholder WordPress-menuen som eneste datakilde.
  • Menu Inspector er opdelt i Indhold, Layout, Tekst, Farver og Mobil og linker direkte til menupunkterne.
  • Mobil Hamburger kan åbne som Dropdown, Panel fra højre eller Panel fra venstre; Esc, klik udenfor og luk efter valg understøttes.
  • VD-PAGE-STATUS-001: Side-Designer viser WordPress-status og har Gem & publicér / Gem & gør til kladde uden en separat VDM-status.

0.1.53 – Gennemsigtig elementbaggrund

  • BUG-18: Når Gennemsigtig baggrund er slået til på Tekst, males Designer-elementet nu fysisk transparent, så den nærmeste Kasse/Sektions farve ses igennem.
  • Samme regel gælder Menu og gennemsigtig Billede-boks.
  • Markering, hover, resize og canonical geometri ændres ikke.
  • Preview og frontend bevarer Rendererens eksisterende transparente paint-kontrakt.

0.1.50 – Sidekonvertering og AKVPK theme-migration

  • Nyt Konvertering-punkt med enkelt/batch forberedelse, QA-preview og separat godkendelse.
  • Konvertering er ikke-destruktiv: original post_content overskrives ikke, og batch aktiverer aldrig sider automatisk.
  • AKVPK theme 1.3.0 flytter den tekniske theme-identitet til akvpk og bruger https://akvpk.dk/.
  • Tema/Shell viser nu korrekt aktiv Visual Designer Header/Page/Footer-runtime.

0.1.49 – Aktiv shell og hjemmesidevalg

  • Visual Designer Header og Footer kan nu bruges live på Visual Designer-sider. Renderer-kæden er Header → side → Footer.
  • Ikke-konverterede WordPress-sider ændres ikke, og manglende/inaktiv Header eller Footer falder sikkert tilbage til selve siden.
  • Under Sider kan en Visual Designer-side publiceres og vælges som WordPress-hjemmeside direkte i Manageren.
  • Hjem – Visual Designer er fortsat separat fra den gamle Hjem-side, indtil brugeren vælger den som Hjem.
  • Header/Footer-administrationen viser nu den aktive Shell-status samt standard Header/Footer.
  • AKVPK theme 1.2.2 synkroniserer synlig version og updater-runtime; ingen layoutændring.

0.1.48 – Lag, Button parity og oprydning

  • Ny Elementer | Lag-fane i venstre panel. Lag viser Sektion/Kasse/leaf-hierarkiet og kan vælge et element, selv når et andet element dækker det 100%.
  • BUG-17: Knapramme og radius gengives på den synlige klikflade på frontend, og Header/Footer-preview nulstiller ikke længere canonical rammefarver.
  • Den gamle Header/Footer-konverteringsbrugerflade og converter-runtime er fjernet. Eksisterende Header/Footer-modeller, valg og historik ændres ikke.
  • Canvas starter fortsat i Fit; manuel zoom er kun sessionsadfærd. BUG-02 multiline selection fra 0.1.47 beholdes som release-gate.
  • WordPress-temaets synlige navn bliver AKVPK i theme 1.2.1. Slug/mappe/Text Domain forbliver hangar18-base af kompatibilitetshensyn.
  • Theme Shell er fortsat OFF. Menu-UX ændres ikke i denne release.
