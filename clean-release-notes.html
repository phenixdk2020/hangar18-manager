0.1.78 – Hybrid modulsider og fleksible Eventfelter

  • Events, Billedgalleri og Køretøjer: almindelige Visual Designer-elementer kan placeres før, mellem og efter det dynamiske modulindhold.
  • Den eksisterende flow-baserede CollectionPageRenderer bevares, så søgning, sortering, eventarkiv og automatisk indholdshøjde fortsat fungerer.
  • Moduldesign fra 0.1.77 ligger fortsat som en separat tilstand; Indholdselementer er nu standardtilstanden.
  • Eventdetalje, Albumdetalje og Køretøjsdetalje er genbrugelige Visual Designer-sider, hvor almindelige elementer kan sættes omkring de dynamiske detailblokke.
  • Eventfelter: opret, fjern, omdøb og sorter felter med type, aktiv/påkrævet og visning på kort/detalje.
  • Standard Eventfelter: Om arrangementet, Program og Praktiske oplysninger.
  • Nyt Designer-element Eventfelt kan vise et bestemt fleksibelt Eventfelt separat på detail-skabelonen.
