0.1.93

  • Release-gate hærdet: den centrale release kører nu automatisk de aktuelle 0.1.92/0.1.91/0.1.90/0.1.89 QA-gates før pakning.
  • Siteindstillinger, Event/Editor og portable transfer-regressioner er også en obligatorisk del af releaseflowet.
  • Eksport-siden bruger nu konsekvent dansk terminologi i menu, overskrifter, knapper og fejltekster.
  • Canonical backlog er synkroniseret med den aktuelle 0.1.93-baseline og næste store v0.2.0-migration.

0.1.92

  • Dobbelt eksportkontrol: både total-ZIP og den indlejrede portable site-ZIP verificeres før download.
  • Alle filer kontrolleres mod manifestets størrelse og SHA-256, og content-digest genberegnes.
  • Eksporter alt indeholder nu export-summary.json og README.txt med præcis recovery-fil, counts og SHA-256.
  • Den portable ZIP testes med samme fulde preflight som ved import.

0.1.91

  • Formulardesign: justér feltafstand, Kommentar/Besked-højde, samtykkeafstand og knap-padding direkte i Inspector.
  • Samme værdier bruges i Designer, forhåndsvisning og live.
  • Formularer vokser automatisk ved overflow, så submit-knappen ikke kan ende uden for baggrunden.
  • 0.1.90-standardudseendet bevares uændret, hvis de nye felter ikke justeres.

0.1.90

  • Formular-paritet: Kontakt- og Bliv medlem-formularer bruger samme mål i Designer og live.
  • Kommentar/Besked-feltet er nu canonical 168 px i begge visninger; den gamle 112 px Designer-højde er fjernet.
  • Labels, felter, samtykke og submit-knap bruger samme typografi, line-height, padding og spacing.
  • Eksisterende formularer med for lav grid-højde normaliseres sikkert, så Send indmeldelse/Send besked ikke flyder uden for formularens baggrund.
  • Nye formularer reserverer korrekt minimumshøjde fra start.

0.1.89

  • Renere Manager-menu: Konvertering og det gamle Eksport / import-punkt er skjult fra normal navigation.
  • Eksporter alt: Eksport-siden kan nu hente plugin, aktivt tema/parent-theme og en komplet portabel VDM-sitepakke i ét arkiv.
  • Den portable ZIP inde i totalpakken er direkte kompatibel med VDM-importens preflight/importmotor.
  • Sider/layouts/historik, Header/Footer, Events, Køretøjer, Billedgalleri, feltdefinitioner, navigation, medier og Siteindstillinger er med i den portable del.
  • Statusmærker som Klar, Under udvikling og Ikke færdig vises ikke længere ud for Manager-punkterne.

0.1.88

  • Kompakt popup igen: Farvevælger og temafarver fylder ikke længere statisk i Inspector.
  • Klik på farvefeltet åbner den kompakte VDM-popup med farveflade, HEX og standardfarver.
  • Handlingslinjen er Annuller · Tema/Farvevælger · Anvend; Tema skifter til temafarver og Senest brugt uden at lukke popupen.
  • Annuller, Escape og klik udenfor gendanner den oprindelige farve; Anvend gemmer én kontrolleret ændring.
  • Alle Designer-farvefelter bruger fortsat samme picker, inklusive dynamisk genskabte Inspector-felter.

0.1.87

  • Én farvevælger overalt: Designerens gamle v0.1.35-picker er fjernet fra runtime, så alle farvefelter bruger den fælles WordPress/VDM-farvevælger.
  • Baggrund, Tekstfarve, Overskriftsfarve, Rammefarve samt hover/focus/accent- og modulfarver bruger nu samme UI.
  • Temafarver er direkte genveje i farvevælgeren, sammen med Senest brugt og fri HEX/farve.
  • Dynamisk genopbyggede Inspector-felter bliver eksplicit geninitialiseret, så browserens native Windows-farvedialog ikke længere dukker op på enkelte felter.
  • Farven committes fortsat først ved Anvend; Annuller/Escape gendanner den tidligere farve.

0.1.86

  • Ny Siteindstillinger-side med Webstedstitel, Slogan, Virksomhed/forening, Kontakt-e-mail og Kontakttelefon.
  • Logo og WordPress site-ikon/favicon kan vælges direkte fra mediebiblioteket.
  • Site-identiteten er nu en eksplicit del af den portable VDM-eksport og importerer logo/site-ikon via sikker medie-ID-remapping.
  • Gamle 0.1.85-eksporter uden siteIdentity bevarer målsitets identitet ved import, så fx “My new WordPress installation” ikke genindføres utilsigtet.

0.1.85

  • Editor, forhåndsvisning og live bruger nu samme kanoniske ydre geometri for Sektion/Kasse, så editorboksen ikke auto-udvider sig større end den gemte/live boks.
  • Nyt Eventfaktabånd med Dato, Tid, Sted, Adresse og Kontakt i samme kompakte kortstil som den tidligere eventside.
  • Faktabåndet er et rigtigt Designer-element med justerbar afstand, kortbredde, padding, farver og typografi.
  • Eventfelt har nu separat størrelse, vægt, skrifttype og linjeafstand for overskrift og indhold.
  • Om arrangementet, Program og Praktiske oplysninger kan vise overskriften selv uden indhold og kan styles individuelt.
  • Adresse og Kontakt er tilføjet som kanoniske Event-datafelter og gemmes gennem den samme ModuleRegistry/ModuleRecord-kontrakt som øvrige Event-data.
  • Nye Eventfelters checkbox-indstillinger gemmes korrekt allerede ved første gem.

0.1.84

  • Ny komplet Eksport / import for en portabel Visual Designer Manager sitepakke.
  • ZIP-pakken indeholder sider og layouts med historik, Header/Footer-templates, moduldata, feltdefinitioner, navigation og originale mediefiler.
  • Import starter med read-only forhåndskontrol og verificerer schema, sikre ZIP-stier og SHA-256 før data kan importeres.
  • Side-, menu-, template- og mediereferencer remappes ved import til et andet site.
  • Nye kanoniske runtime-konstanter hedder VDM_*; gamle H18/Clean-storageidentifikatorer er kun compatibility/migrationslag.

0.1.80 – Komponérbare modulsider og Eventdetalje

  • Events, Billedgalleri og Køretøjer: den faste H1 er flyttet ind i Visual Designer som et normalt Tekst-element. Overskriften kan nu flyttes og styles frit.
  • Eventdetalje: titel, dato/tid, sted, kort beskrivelse og længere beskrivelse er selvstændige Eventværdi-elementer.
  • Eventbillede er et selvstændigt dynamisk Designer-element med højde, crop/contain, fokuspunkt og radius.
  • Om arrangementet, Program og Praktiske oplysninger fortsætter som selvstændige Eventfelt-elementer og flugter med de øvrige eventtekster.
  • Alle de nye dynamiske elementer bruger samme Desktop/Laptop/Tablet/Mobil-geometri som resten af Visual Designer.
  • Den tekniske Data-menu er fjernet fra den normale Manager-navigation. Den interne data-/bindingmodel er bevaret.
  • Migrationsbackup gemmes før både collection-overskrifter og Eventdetalje opgraderes.
