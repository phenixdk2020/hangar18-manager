0.1.77 – Redigerbart moduldesign

  • Events, Billedgalleri og Køretøjer: de tre canonical modulsider kan nu designes direkte i Visual Designer uden at opgive Designer/frontend-paritet.
  • Nyt Moduldesign styrer sidebredde, kolonner pr. breakpoint, kortafstand/maksbredde, baggrund, tekstfarve, padding, radius, billedformat, typografi, accentfarve og sektionsafstand.
  • Designændringer vises live i den samme CollectionPageRenderer som frontend via en autoriseret same-origin preview-override.
  • _old-udseendet er fortsat standardprofil: 90% frame, 3/2/1 kolonner, 22px gap, beige kortkrop og 16:9 coverbilleder.
  • Moduldesign gemmes versionsstyret og følger restore af tidligere Designer-versioner.
  • Alle funktioner fra v0.1.76 bevares, herunder søgning/sortering, eventarkiv, event→album samt Kontakt/Bliv medlem-formularer.
