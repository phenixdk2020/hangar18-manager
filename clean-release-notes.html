0.1.21

  • Designeren har nu tre arbejdsvisninger: Desktop, Laptop og Mobil.
  • Canonical modellen understøtter separat geometry.laptop og geometry.mobile med arv, mens element-ID, indhold og hierarki fortsat er fælles.
  • Laptop arver Desktop som standard; Mobil arver det effektive Laptop/Desktop-layout indtil et lokalt override oprettes.
  • Flytning og resize i Laptop/Mobil ændrer kun den aktive responsive geometri og kan nulstilles til arv.
  • Frontend anvender responsive breakpoint-geometrier fra samme gemte model: Laptop op til 1180 px og Mobil op til 782 px.
  • Responsive parent-højder beregnes ud fra børnene, så mobile stack-layouts ikke skal overlappe efterfølgende indhold.
  • Elementer og Inspector kan foldes ind og ud uafhængigt for at give mere arbejdsplads på mindre skærme.
  • Ny ⇔ Mere canvas-knap folder begge sidepaneler ind eller ud på én gang.
  • Paneltilstanden gemmes lokalt i browseren; almindelige laptop-bredder starter i en kompakt Designer-visning, hvis brugeren ikke allerede har valgt noget andet.
  • Workspace, toolbar og canvas er gjort mere kompakte på laptopskærme, uden at den canonical 120-unit model ændres.
