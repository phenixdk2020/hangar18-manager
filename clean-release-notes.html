0.1.31

  • Flydende Knap: flyttehåndtaget bruger nu et separat parent-relativt overlay-flow og går ikke gennem det normale Over/Under/Venstre/Højre celle-split. Knappen reserverer ingen grid-række og påvirker ikke parent auto-grow.
  • Rich text selection: Fed og Kursiv bevarer nu den markerede tekst efter formattering. Selection gendannes ud fra tekst-offsets, så DOM-wrapping med strong/em ikke kollapser markeringen; samme mekanisme bruges for toolbaren generelt.
  • Theme Shell: første runtime-kontrakt til konvertering af Hangar18 Base Theme er tilføjet. Cutover er eksplicit slået fra som standard, så den nuværende frontend ikke ændres før parity-QA.
  • Header/Footer migration: eksisterende globale Visual Designer Header/Footer-modeller kobles til Theme Shell-resolution som fundament for senere 1:1-konvertering af den eksisterende Hangar18 header/footer.
  • Sikker baseline: Hangar18 Base Theme 1.2.0 forbliver fallback og visuel reference, indtil Desktop/Laptop/Mobil parity er godkendt.
