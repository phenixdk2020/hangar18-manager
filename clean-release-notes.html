0.1.23

  • Ny global Header / Footer Designer med separate canonical modeller og separate ikke-destruktive versionshistorikker for Header og Footer.
  • Header/Footer genbruger den samme 120-unit / 8-px Visual Designer-layoutmotor samt Desktop/Laptop/Mobil som almindelige sider. Fase 1 bruger Sektion, Kasse, Tekst og Billede; Menu/Knap/Ikon kommer efter Header/Footer-layout-QA.
  • Header/Footer kan gemme klargøringsindstillinger som sticky Header, overlay og content width, men 0.1.23 overtager bevidst ikke temaets offentlige Header/Footer endnu for at undgå dobbelt shell før Theme-integration.
  • Managerens moduler får visuel status: grøn Klar og gul Under udvikling / Ikke færdig, så det er tydeligt hvilke områder der kan bruges.
  • Menu-redesign er bevidst udskudt, til Menu-elementet kan bygges direkte ind i Header/Footer Designer.
  • Nye Sektioner, Kasser, Tekst- og Billede-elementer starter med større, mere brugbare højder. Ny Tekst får 12 px standard-padding.
  • Den grønne selection-markering er tykkere og tydeligere.
  • Ændringsbeskrivelsen ved Gem er nu valgfri. Hvis feltet er tomt, genererer Visual Designer automatisk en kort ændringsbeskrivelse til versionshistorikken.
  • Tekst-preview i Designer viser hele teksten og bevarer linjeskift og tomme linjer.
  • Manuel billedredigering er tydeliggjort som separat billedindhold, og Tilbage til Vis hele billedet rydder nu den manuelle billedramme og inline-positionering korrekt.
  • Hierarki, responsive geometri, Export, Tema/Shell, programbackup og SHA-verificeret updater fra 0.1.22 er bevaret og regressions-testet.
