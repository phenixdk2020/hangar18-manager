0.1.20

  • Hjørneradius er nu en fælles styling-egenskab på Sektion, Kasse, Tekst og Billede.
  • Tekst-elementer kan have gennemsigtig eller valgt baggrund, separat tekstfarve, separat overskriftsfarve og padding.
  • Billedboksen og selve billedindholdet kan redigeres uafhængigt.
  • Manuel billedtilstand viser en separat sandfarvet ramme med egne flytte- og resize-håndtag.
  • Manuelt billedindhold gemmer egne X/Y/bredde/højde i pixels, så billedets størrelse ikke automatisk følger en senere ændring af billedboksen.
  • Lås proportioner er aktiveret som standard ved manuel billedskalering.
  • Vis hele / Fyld / Original / Stræk bevares som hurtige billedtilstande, og manuel redigering kan nulstilles tilbage til Vis hele billedet.
  • Preview og frontend renderer de nye tekstfarver, baggrunde, hjørner og den manuelle billedgeometri.
  • Ændringsbeskrivelsen ved sidegemning skal være skrevet af brugeren og kan ikke længere erstattes lydløst af editorens interne sidste handling.
